## What this system is

Airfoil is a static AI-news site generated by a local Go agent that runs on a schedule or on demand. The agent ingests from RSS, Hacker News, Reddit, Hugging Face Papers, and GitHub; normalizes, embeds, clusters, scores, and summarizes items via an LLM fallback chain; writes Markdown stories and JSON indexes into the repo; then commits and pushes. The React + Vite site consumes the generated JSON and Markdown at build time. No database, no server — Git is the storage layer.

## Architecture

**Go agent** (`github.com/papitsho/airfoil`):
- `cmd/airfoil` — thin Cobra CLI (`main`, `run`, `version`, `doctor`)
- `internal/config` — `Config` struct, `Load(Options)`, env + JSON file loading, derived paths (`ItemsDir`, `CacheDir`, `IndexPath`, `StatePath`, `StoriesPath`, `EmbedCachePath`), source enablement, validation
- `internal/model` — core types: `Item`, `Cluster`, `Story`, `IndexEntry`, `Index`, `State` (dedup), `Metrics`, tier constants (`TierMajor`, `TierNotable`, `TierMinor`)
- `internal/ingest` — `Adapter` interface, `Runner` orchestrating adapters: `hnAdapter`, `rssAdapter` (Reddit, HFPapers, GitHub use RSS), HTTP fetcher with timeout/retry
- `internal/normalize` — pure functions: `Build(Raw, now, maxExcerpt) → Item`, `Dedupe`, `CanonicalURL`, `ItemID`, `ExtractRepoURL`, `ExtractPaperURL`, text utilities (`StripHTML`, `Excerpt` capped at 300 chars)
- `internal/store` — `ReadJSON[T]`, `WriteJSON`, atomic writes, fallback reads

**Site** (`site/`):
- `src/types/story.ts` — mirrors Go frontmatter: `Story`, `Source`, `FilterState`, `DateWindow`, `SortOrder`, `SourceType` (`lab` | `community` | `press`)
- `src/pages/*` — `HomePage`, `FeedPage`, `StoryPage`, `SearchPage`, `TopPage`, `ShipPage`, `DigestPage`
- `src/components/*` — `Header`, `LeftRail`, `RightRail`, `StoryCard`, `StoryDetail`, `ActiveFilterBar`, `TagPill`, `ScoreBadge`, `AirfoilSVG`, `Footer`, `MobileOverlay`
- `src/hooks/useAirfoilSignals.ts` — filter state machine (date, tag, source, query, sort), `useTheme.ts`
- `src/styles/tokens.css` — single source of design tokens

**Config** (`config/`): `sources.json`, `scoring.json`, `keywords.json` — loaded into `Config` at startup.

**Data** (`data/`): generated `items/*.json`, `index.json`, `state.json`, `stories.json`; `cache/` (embeddings, **never committed**).

**Dependency direction**: `cmd/airfoil` → `internal/config` → `internal/{ingest,normalize,store,model}`; site reads only `data/` and `site/src/content/stories/`.

## Key flows

**Full pipeline (`./airfoil run`)**:
1. `cmd/airfoil/main.go` → `root.go` → `app.run()` loads `config.Load`, creates `ingest.New(cfg, log)`
2. `ingest.Runner.Run(ctx, state, since)` → each `Adapter.Fetch` → `normalize.Raw` items
3. `normalize.Build` each raw → `model.Item` (excerpt ≤300 chars, canonical URL, extracted repo/paper URLs)
4. `normalize.Dedupe` against `state.Seen` → new items written to `data/items/*.json`
5. Embedder (Ollama/Gemini per `AIRFOIL_EMBEDDER`) → vectors cached in `data/cache/`
6. Cluster (O(n²) similarity) → `model.Cluster` with tier assignment
6. Score using `config/scoring.json` tier weights + `keywords.json` boosts + recency decay → ranked `Index`
7. LLM summarize (Gemini → NVIDIA NIM → OpenRouter → Ollama fallback) → `model.Story`
8. Write `site/src/content/stories/*.md` + `data/index.json` + `data/state.json` + `data/stories.json`
9. Validate → `git commit -m "content: YYYY-MM-DD — N stories"` → `git push`

**Site render (build time)**:
1. `npm run build` → Vite + `tsc` reads `data/index.json` + `site/src/content/stories/*.md`
2. `App.tsx` router → pages consume `Story[]` via props
3. `useAirfoilSignals` derives filtered/sorted lists from raw stories
4. Zero client JS except `/search` page

**Idempotent re-run**:
- `State.Seen(id)` checks `data/state.json` (per-day keys) → `Dedupe` drops already-seen items → zero new stories on second run same day

## Glossary

**Item** — normalized, deduplicated ingest unit with title, canonical URL, excerpt (≤300 chars), source metadata, published time, extracted repo/paper URLs; stored in `data/items/*.json`
**Cluster** — group of similar Items from embedding similarity; assigned a tier (Major/Notable/Minor) and becomes one Story
**Story** — publishable unit: one Cluster → LLM summary + frontmatter (title, date, tier, tags, sources[], clusterId); written as Markdown in `site/src/content/stories/`
**Index** — ranked list of `IndexEntry` (Story ref + score) serialized to `data/index.json` for site consumption
**State** — dedup tracker: `Seen(id)` / `MarkSeen(id, day)` persisted to `data/state.json`; key is ItemID (hash of canonical URL)
**Source** — configured input in `sources.json` with `type` (RSS, HN, Reddit, HFPapers, GitHub), `url`, `options`, `enabled`
**Tier** — importance level: `TierMajor` (0), `TierNotable` (1), `TierMinor` (2); drives scoring weight via `Scoring.TierWeight(tier)`
**Adapter** — `ingest.Adapter` implementation (`hnAdapter`, `rssAdapter`) that fetches and returns `[]normalize.Raw`
**Raw** — pre-normalization struct from adapter: title, link, content, published, source name/type
**Embedder** — vector provider: `ollama` (local default) or `gemini` (CI); configured via `AIRFOIL_EMBEDDER` + model env vars
**FilterState** — client-side filter combination: `date` (ALL|24H|7D), `tag`, `source`, `query`, `sortBy` (newest|score|cluster)

## Conventions

**Go**:
- No globals, no `init()`. Config passed explicitly as `*config.Config`.
- Errors: `fmt.Errorf("stage: %w", err)` wrapping at each layer.
- Logging: `log/slog` only, structured.
- All external calls take `context.Context` with timeout.
- Pure functions (`normalize.Build`, `normalize.Dedupe`, `cluster`, `score`) have table-driven tests in `*_test.go`.
- `internal/` for all logic; `cmd/airfoil` is thin main.
- Atomic JSON writes via temp file + rename (`store.WriteJSON`).

**Configuration**:
- `.env.example` → copy to `.env` (gitignored). CI uses GitHub Secrets.
- Env vars: `AIRFOIL_CONFIG_DIR`, `AIRFOIL_DATA_DIR`, `AIRFOIL_EMBEDDER`, `AIRFOIL_LOG_LEVEL`, `AIRFOIL_STORIES_DIR`, `SITE_URL`, provider keys (`GEMINI_API_KEY`, `NVIDIA_NIM_API_KEY`, `OPENROUTER_API_KEY`, `GITHUB_TOKEN`, `REDDIT_USER_AGENT`), Ollama/Gemini model IDs.
- JSON configs in `config/` loaded into `Config` struct; `Config.Validate()` gates pipeline.

**Content limits** (enforced in `normalize`, not edges):
- Excerpt max 300 chars (`normalize.Excerpt`).
- Max one quote per source, <15 words.
- Summaries are original LLM prose, not extracted sentences.
- Every story links to all its sources.

**React / Site**:
- Types in `site/src/types/story.ts` mirror Go frontmatter exactly.
- Zero client JS except `/search` page.
- Design tokens only in `site/src/styles/tokens.css`; reference via CSS vars everywhere.
- Dense layout target: ~25 stories per desktop screen on `/feed`.
- Component-scoped CSS (`.module.css` or co-located `.css`).

**Git / Commits**:
- Human commits: conventional (`feat:`, `fix:`, `chore:`).
- Agent commits: `content: YYYY-MM-DD — N stories` — only commits touching `data/` or `site/src/content/`.
- Never commit `data/cache/` (embeddings regenerable, huge).
- Validation failure aborts before commit; never push broken site.

**LLM fallback chain**: Gemini → NVIDIA NIM → OpenRouter → Ollama. Every call has timeout + fallback. Configured via env.

**Rate limits**: GitHub token optional (60→5000/hr). Reddit requires descriptive `User-Agent` or returns 429.
