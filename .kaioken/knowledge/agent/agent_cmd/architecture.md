Four files in agent/cmd/airfoil/ form the CLI layer. main.go calls newRootCmd().Execute() with minimal error handling. root.go constructs the root Cobra command, binds persistent flags, and implements PersistentPreRunE that loads config via config.Load (skipped for version subcommand), creates an app struct holding *config.Config, *slog.Logger, and a since duration override, and attaches version and doctor subcommands. newLogger in root.go builds a structured text logger with wall-clock timestamps; --verbose forces debug level. version.go prints version (set via -ldflags at build), GOOS/GOARCH, and Go runtime version. doctor.go defines newDoctorCmd taking the app pointer; its RunE calls runDoctor which writes a structured report to the provided io.Writer: paths, enabled sources grouped by tier, embedder config (Ollama or Gemini with API key check), LLM chain fallback order (Gemini, NVIDIA NIM, OpenRouter, Ollama) with configured status, and ingest advisories (GitHub token, Reddit User-Agent). Blocking errors (missing Gemini key, no LLM configured) return an error; advisories only warn.
