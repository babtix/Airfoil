config.go:Load(Options) is the entry point. It calls loadDotEnv(".env") (dotenv.go) which parses KEY=value lines, respects existing env vars, and supports export prefix, quoted values, and trailing # comments — no interpolation. Load then builds Config with precedence: CLI flag > env var > hardcoded default. Paths (DataDir, ConfigDir, StoriesDir) are resolved here. LLMConfig holds four provider credential sets (Gemini, NvidiaNIM, OpenRouter, Ollama) each with APIKey+Model; ProviderCreds.Configured() gates usage. EmbedConfig selects provider (ollama|gemini) and holds provider-specific fields. IngestConfig carries GitHubToken and RedditUserAgent. loadFiles() (config.go) reads the three JSON files via store.ReadJSON (files.go). sources.json deserializes into []Source with union SourceOptions; validSourceTypes guards known types (rss, hn, reddit, hf_papers, github). scoring.json maps to Scoring struct with nested structs for clustering, weights, recency, caps, tiers, limits, retention; Scoring.TierWeight(tier) looks up stringified tier. keywords.json maps to Keywords with builder/hype signal arrays and topic_tags map. Validate() (config.go) runs after loading: checks at least one enabled source, unique source IDs, valid types, tier 1-5, scoring thresholds in range, all five tier_weights present, major_min_score > notable_min_score, positive caps/limits/retention days, embed provider allowlist, non-empty keyword signal arrays. Derived path methods (ItemsDir, CacheDir, DigestDir, IndexPath, StatePath, StoriesPath, EmbedCachePath) join DataDir subdirectories. EnabledSources() filters Sources by Enabled flag.
