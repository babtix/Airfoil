Package model (agent/internal/model/types.go) contains zero external dependencies — only the Go standard library. The primary types form a linear pipeline: Item (normalized article) → Cluster (group of Items with a Centroid vector excluded from JSON) → Story (scored, summarized cluster with Takeaways and Body) → IndexEntry (slim record for data/index.json). StorySource and SourceMetrics capture outbound links and per-source metrics for the site. State holds SeenURLs (item ID → YYYY-MM-DD) and Cursors (per-source high-water marks) with methods Seen() and MarkSeen() for idempotency. SourceType(tier int) encodes the tier→category mapping used by the writer: tier≤3=lab, tier=4=press, else=community. Constants TierMajor/TierNotable/TierMinor define story tiers.
