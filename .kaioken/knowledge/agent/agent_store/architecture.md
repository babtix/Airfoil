The package exports five functions in json.go: ReadJSON[T] decodes a file into a generic type T, returning a wrapped error on missing or malformed files; ReadJSONOr[T] wraps ReadJSON to return a caller-supplied fallback only when the file does not exist (parse errors still propagate); WriteJSON marshals any value as indented JSON with a trailing newline and delegates to WriteFile; WriteFile implements the atomic write — creates parent directories (0755), writes to a temp file named .tmp-<basename>-* in the same directory, syncs, closes, removes any existing destination (required on Windows), then renames the temp file into place; a deferred cleanup removes the temp file on any early failure. Exists is a thin wrapper around os.Stat. No internal state, locks, or background goroutines — pure file-system operations.
