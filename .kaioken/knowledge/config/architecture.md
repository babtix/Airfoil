keywords.json exports four top-level keys: builder_signals (30 phrases), builder_structural_signals (4 boolean flags), hype_signals (21 phrases), and topic_tags (9 categories each with 4–8 keywords). All builder/hype signals are matched case-insensitively against concatenated title+excerpt; each distinct match counts once and is capped by scoring.json caps. scoring.json is a flat parameter bag read by the ranking/clustering engine: clustering.similarity_threshold (0.82) and window_hours (48) drive embedding-based deduplication; weights dict assigns points per signal source (sources 22, tier 25, hn 6, reddit 5, builder 4, hype 6); tier_weights maps tier 1–5 to multipliers (1.0 → 0.3); recency.half_life_hours (48) controls exponential decay; caps limit builder/hype signals to 5 each and LLM calls to 15/run; tiers.major_min_score (70) and notable_min_score (40) gate digest placement; limits constrain output fields (excerpt 300 chars, summary 80 words, etc.); retention sets TTLs for items/seen URLs (30d) and embedding cache (7d). sources.json contains a sources array of 17 objects, each with id, name, type (rss|hf_papers|github|hn|reddit), url, tier (1–5), tags, enabled, and type-specific options (e.g., GitHub queries/min_stars, HN min_points/hours_back, Reddit limit/min_score). Tier 1 = official lab blogs (5 RSS feeds); Tier 2 = research feeds (HF blog, HF daily papers API, 3 arXiv RSS); Tier 3 = GitHub trending search API with 5 queries; Tier 4 = tech press RSS (3); Tier 5 = community APIs (HN Algolia, 2 Reddit hot endpoints).
