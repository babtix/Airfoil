All signal phrases in keywords.json are lower-case in source but matched case-insensitively; keep new entries lower-case. builder_structural_signals are not text phrases — they are boolean flags set by the ingest pipeline (has_repo_url, has_paper_url, source_tier_1, source_tier_3). scoring.json weights must sum to a sensible scale; the comment warns to validate changes with `airfoil rank` against top-20 output before committing. tier_weights keys are strings ("1"–"5") not numbers; preserve string keys when editing. caps.builder_signal_max and hype_signal_max cap distinct matches per item, not total occurrences. sources.json: every new source requires a unique id, valid type enum, tier 1–5, and enabled boolean; type-specific options object is optional but validated per fetcher. Feed URLs must be verified with `airfoil doctor` before enabling — the comment notes feed paths change. GitHub source uses REST search API with queries array, created_within_days, min_stars, max_per_query; HN uses Algolia search_by_date with queries, min_points, hours_back; Reddit uses hot.json with limit, min_score. Retention days (items, seen_urls, embedding_cache) are independent; embedding_cache_days (7) is shorter than item TTL (30).
