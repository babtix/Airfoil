Three flat JSON files in data/ directory with no code dependencies. index.json is the primary publish artifact — an array of story summaries sorted by score descending, each containing id, slug, title, summary, score (68-98), tier (major/notable), tags array, builder_relevant boolean, ISO8601 date, and cluster_size integer. stories.json mirrors the same 12 IDs with full content: body (string array), takeaways (string array), and sources array with name, type (lab/community/press), tier (1-5), url, and optional metrics (points, comments, upvotes, stars). state.json maintains incremental pipeline state: seen_urls object (empty in sample), cursors object (empty), and last_run null. Data flows one-way: pipeline writes all three; downstream consumers (site generator, API) read index.json for listings and stories.json for detail pages.
