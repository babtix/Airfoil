Runtime data artifacts produced by the pipeline: a ranked story index (index.json), deduplication state tracking (state.json), and fully hydrated story content (stories.json). The index holds 12 scored stories with tier classification (major/notable), builder relevance flags, and cluster sizes; stories.json expands each with body paragraphs, takeaways, and typed source citations; state.json tracks seen URLs, source cursors, and last run timestamp for incremental processing.
