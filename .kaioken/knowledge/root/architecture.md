The repo splits into four directories: `agent/` (Go module `github.com/papitsho/airfoil` with `cmd/airfoil` thin main and `internal/` pure-logic packages), `site/` (React+Vite+Astro, entry `site/src/main.tsx` → `App.tsx` router → pages in `site/src/pages/`), `config/` (JSON files: `sources.json`, `scoring.json`, `keywords.json`), and `data/` (generated: `items/*.json` → `index.json` ranked → `state.json` dedup → `site/src/content/stories/*.md` published). Config loads via `config.Load(Options)` returning `*Config` with path helpers (`ItemsDir()`, `CacheDir()`, `IndexPath()`, `StatePath()`, `StoriesPath()`, `EmbedCachePath()`). LLM provider chain (Gemini → NVIDIA NIM → OpenRouter → Ollama) and embedder (Ollama local default, Gemini CI) are env-driven. All external calls take `context.Context`; errors wrap with `fmt.Errorf("stage: %w", err)`; logging uses `log/slog` only.
