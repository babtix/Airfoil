## System Overview

Airfoil is a **static AI-news site** generated by a local Go agent. The agent runs on a schedule (GitHub Actions) or on demand, ingests from multiple sources, processes items through a nine-stage pipeline, writes Markdown stories and JSON indexes into the repository, then commits and pushes. The React + Vite site consumes the generated JSON and Markdown at build time. **No database, no server — Git is the storage layer.**

```

│                           AIRFOIL SYSTEM ARCHITECTURE                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │

│  │   SOURCES    │     │  GO AGENT    │     │   GIT REPO   │                │
```

## Go Agent Architecture

The Go agent follows a standard layout with a thin CLI entry point and all logic in `internal/` packages.

### CLI Entry Point

```
agent/cmd/airfoil/
├── main.go        # Binary entry
├── root.go        # Root command, version, doctor
└── run.go         # `run` subcommand — orchestrates full pipeline
```

The `run` command loads configuration, creates the ingest runner, executes the pipeline, validates output, then commits and pushes.

#### State (Deduplication)

`agent/internal/model/types.go:123-151`

```go
// State is data/state.json — what makes the agent idempotent (R7).
type State struct {
	// SeenURLs maps an item ID to the date it was first seen, as YYYY-MM-DD.
	SeenURLs map[string]string `json:"seen_urls"`
	// Cursors holds per-source high-water marks.
	Cursors map[string]string `json:"cursors"`
	LastRun *time.Time        `json:"last_run"`
}

// NewState returns an empty, non-nil State.
func NewState() *State {
	return &State{
		SeenURLs: map[string]string{},
		Cursors:  map[string]string{},
	}
}

// Seen reports whether an item ID has already been ingested.
func (s *State) Seen(id string) bool {
	_, ok := s.SeenURLs[id]
	return ok
}

// MarkSeen records an item ID as ingested on the given day.
func (s *State) MarkSeen(id string, day time.Time) {
	if s.SeenURLs == nil {
		s.SeenURLs = map[string]string{}
	}
	s.SeenURLs[id] = day.UTC().Format(time.DateOnly)
}
```

## Agent Pipeline Stages

The full pipeline executes in this sequence:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         AGENT PIPELINE (./airfoil run)                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. INGEST          Adapter.Fetch() → []normalize.Raw                       │
│       │                                                                     │
│       ▼                                                                     │
│  2. NORMALIZE       normalize.Build() → model.Item                          │
│       │    (excerpt ≤300 chars, canonical URL, repo/paper extraction)       │
│       ▼                                                                     │
│  3. DEDUPE          normalize.Dedupe() against State.Seen                   │
│       │    → new items written to data/items/*.json                         │
│       ▼                                                                     │
│  4. EMBED           Embedder (Ollama/Gemini) → vectors cached in data/cache/│
│       │                                                                     │
│       ▼                                                                     │
│  5. CLUSTER         O(n²) cosine similarity → model.Cluster + tier assign   │
│       │                                                                     │
│       ▼                                                                     │
│  6. SCORE           config/scoring.json weights + keywords.json boosts      │
│       │    + recency decay → ranked model.Index                             │
│       ▼                                                                     │
│  7. SUMMARIZE       LLM fallback chain (Gemini → NVIDIA → OpenRouter →      │
│       │    Ollama) → model.Story                                            │
│       ▼                                                                     │
│  8. WRITE           site/src/content/stories/*.md + data/index.json         │
│       │    + data/state.json + data/stories.json                            │
│       ▼                                                                     │
│  9. COMMIT & PUSH   git commit -m "content: YYYY-MM-DD — N stories"         │
│       │    git push                                                         │
│       ▼                                                                     │
│  VALIDATION GATE    Abort on failure — never push broken site (R9)          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### Stage Details

| Stage | Package | Key Function/Type | Output |
|-------|---------|-------------------|--------|
| 1. Ingest | `internal/ingest` | `Runner.Run(ctx, state, since)` → `Adapter.Fetch()` | `[]normalize.Raw` |
| 2. Normalize | `internal/normalize` | `Build(Raw, now, maxExcerpt) → Item` | `model.Item` (excerpt ≤300 chars) |
| 3. Dedupe | `internal/normalize` | `Dedupe(items, state) → (newItems, seenItems)` | New items to `data/items/*.json` |
| 4. Embed | `internal/embed` | `Embedder.Embed(texts) → [][]float32` | Vectors in `data/cache/embeddings.json` |
| 5. Cluster | `internal/cluster` | `Cluster(items, embeddings) → []Cluster` | `model.Cluster` with tier |
| 6. Score | `internal/score` | `Score(clusters, config) → Index` | `model.Index` (ranked) |
| 7. Summarize | `internal/llm` | `Summarize(cluster) → Story` | `model.Story` |
| 8. Write | `internal/write` | `Write(stories, index, state)` | Markdown + JSON files |
| 9. Commit/Push | `cmd/airfoil/run.go` | `git commit` + `git push` | Remote repo updated |

## Git as Storage Layer

Git is the **sole persistence layer**. No database, no object store.

### Committed Artifacts

| Path | Description | Regenerable? |
|------|-------------|--------------|
| `data/items/*.json` | Normalized, deduplicated items | Yes (from sources) |
| `data/index.json` | Ranked `IndexEntry` list for site | Yes (from items + scoring) |
| `data/state.json` | `State` (dedup tracker, cursors) | **No** — source of truth for idempotency |
| `data/stories.json` | Authoritative `Story[]` record | Yes (from clusters + LLM) |
| `site/src/content/stories/*.md` | Markdown story files (frontmatter + body) | Yes (from `stories.json`) |

### Never Committed

| Path | Reason |
|------|--------|
| `data/cache/` | Embeddings are huge and regenerable (R5) |
| `.env` | Secrets (R4) |

### Commit Conventions

| Committer | Message Format | Touches |
|-----------|----------------|---------|
| Human | Conventional (`feat:`, `fix:`, `chore:`) | Any |
| Agent | `content: YYYY-MM-DD — N stories` | Only `data/` and `site/src/content/stories/` |

### Go ↔ TypeScript Mirror

The TypeScript types in `site/src/types/story.ts` **exactly mirror** the Go frontmatter/JSON serialization.

|---------|-----------------|---------------|

| `model.SourceType(tier)` | `SourceType` | `'lab' \| 'community' \| 'press'` |

#### TypeScript Definitions

`site/src/types/story.ts:1-30`

```typescript
export type SourceType = 'lab' | 'community' | 'press';

export interface Source {
  name: string;
  url: string;
  type: SourceType;
  tier?: number;
  metrics?: {
    points?: number;
    comments?: number;
```

| Limit | Enforcement | Rule |
|-------|-------------|------|
| Excerpt ≤ 300 chars | `normalize.Excerpt()` | R1 |
| Max 1 quote per source, <15 words | LLM prompt + validation | R2 |
| Every story links all sources | `Story.Sources` populated from cluster | R3 |
| Summaries = original LLM prose | Prompt constraint | R1 |

## Data Flow & Idempotency

### Idempotent Re-run Guarantee

The agent is **idempotent** (R7): running twice in a row produces zero duplicate stories.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         IDEMPOTENCY FLOW                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Run 1:                                                                     │
│  1. Ingest → Items A, B, C                                                 │
│  2. Normalize → Items with IDs (sha256(canonicalURL)[:16])                 │
│  3. State.Seen(id) → all false                                             │
│  4. State.MarkSeen(id, today) → State.SeenURLs[id] = "2025-01-15"         │
│  5. Write data/state.json                                                  │
│                                                                             │
│  Run 2 (same day):                                                          │
│  1. Ingest → Items A, B, C (same URLs)                                     │
│  2. Normalize → same IDs                                                   │
│  3. State.Seen(id) → **true** for all                                      │
│  4. Dedupe drops all → zero new items                                      │
│  5. Zero new clusters → zero new stories                                   │
│  6. Validation passes (no new content)                                     │
│  7. No commit (or empty commit skipped)                                    │
│                                                                             │
│  Run 3 (next day):                                                          │
│  1. State.Seen(id) → true (but date differs)                               │
│  2. **Current implementation**: State keys are per-day (YYYY-MM-DD)        │
│  3. New items with same URL but different day → **treated as new**         │
```

All secrets and runtime configuration via environment (R4). `.env` is gitignored; CI uses GitHub Secrets.

| `AIRFOIL_STORIES_DIR` | Markdown output directory | `site/src/content/stories` |

| `GEMINI_API_KEY` | Google Gemini API key | (required for Gemini) |
| `GEMINI_MODEL` | Gemini chat model | `gemini-2.0-flash` |
| `GEMINI_EMBED_MODEL` | Gemini embedding model | `text-embedding-004` |
| `NVIDIA_NIM_API_KEY` | NVIDIA NIM API key | (required for NIM) |
| `NVIDIA_NIM_MODEL` | NIM chat model | `meta/llama-3.3-70b-instruct` |
| `OPENROUTER_API_KEY` | OpenRouter API key | (required for OpenRouter) |
| `OPENROUTER_MODEL` | OpenRouter model | `meta-llama/llama-3.3-70b-instruct:free` |
| `OLLAMA_HOST` | Ollama daemon URL | `http://localhost:11434` |
| `OLLAMA_CHAT_MODEL` | Ollama chat model | `llama3.1` |
| `OLLAMA_EMBED_MODEL` | Ollama embedding model | `nomic-embed-text` |
| `GITHUB_TOKEN` | GitHub API token (raises 60→5000/hr) | (optional) |
| `REDDIT_USER_AGENT` | Reddit API User-Agent | `airfoil/0.1` |

**LLM Fallback Chain** (every call has timeout + fallback):
1. **Gemini** (if `GEMINI_API_KEY` + `GEMINI_MODEL` configured)
2. **NVIDIA NIM** (if `NVIDIA_NIM_API_KEY` + `NVIDIA_NIM_MODEL` configured)
3. **OpenRouter** (if `OPENROUTER_API_KEY` + `OPENROUTER_MODEL` configured)
4. **Ollama** (local, always available if running)

**Embedder Selection**: `AIRFOIL_EMBEDDER=ollama` (local default) or `gemini` (CI).
